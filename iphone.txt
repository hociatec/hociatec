### 1. Créer un avis / commentaire sur un produit commandé
**Endpoint** : `POST /api/orders/{orderId}/items/{orderItemId}/review`  
**Authentification** : JWT utilisateur connecté (client).  
**Pré-requis** :
- la commande `{orderId}` appartient à l’utilisateur et est au statut `delivered`.  
- l’article `{orderItemId}` correspond à un produit (pas d’avis sur les lignes sans produit).  
- un seul avis par ligne (la route renvoie une erreur si un avis existe déjà).  
  
**Corps JSON** :
```json
{
  "score": 1,        // entier entre 1 et 5
  "comment": "..."   // optionnel, texte libre
}
```
**Réponse succès** (`200`) :
```json
{
  "status": "success",
  "data": {
    "review": {
      "id": 42,
      "score": 5,
      "comment": "Produit impeccable",
      "createdAt": "2025-12-08T15:10:00+00:00",
      "author": { "id": 903, "displayName": "Jean D." },
      "orderItemId": 123
    }
  }
}
```
  
### 2. Identifier les commandes à évaluer
**Endpoint** : `GET /api/orders/me/pending-reviews`  
**Authentification** : JWT utilisateur connecté (client).  
Retourne les lignes d’articles livrées sans avis afin d’afficher un lien “Donner votre avis” :  
```json
{
  "status": "success",
  "data": {
    "items": [
      {
        "orderId": 10,
        "orderNumber": "CMD-2024-0010",
        "orderCreatedAt": "2024-12-01T09:00:00+00:00",
        "orderItemId": 123,
        "product": { "id": 55, "name": "Caméra Pro", "sku": "CAM-PRO" }
      }
    ]
  }
}
```
  
### 3. Afficher les avis publics sur une fiche produit
**Endpoint** : `GET /api/public/catalog/products/{slug}/reviews`  
**Query params** : `page` (défaut 1), `perPage` (défaut 10, max 50).  
**Usage** : côté fiche produit (pas besoin de token).  
```http
GET /api/public/catalog/products/camera-hd/reviews?page=1&perPage=5
```
**Réponse** :
```json
{
  "status": "success",
  "data": {
    "items": [
      {
        "id": 42,
        "score": 5,
        "comment": "Qualité irréprochable",
        "createdAt": "2025-12-08T15:10:00+00:00",
        "author": { "id": 903, "displayName": "Jean D." }
      }
    ],
    "meta": {
      "page": 1,
      "perPage": 5,
      "total": 8,
      "average": 4.6
    }
  }
}
```
  
### 4. Rappels utiles pour l’intégration
- Chaque produit retourne déjà ses stats (`reviews.count`, `reviews.average`) via `GET /api/public/catalog/products/{slug}` pour afficher la note moyenne immédiatement.  
- Les commandes (`GET /api/orders/me` / `GET /api/orders/{id}`) incluent désormais, par ligne, `canReview` et `review` afin d’afficher soit le formulaire d’avis, soit l’avis déjà déposé.  
- Toute modification d’avis n’est pas encore supportée : il faut supprimer puis recréer un avis si besoin (fonctionnalité future).
